# Personal Fantasy Assistant

A private, personal project for one user: me.

## What it does
Connects to the Yahoo Fantasy Sports API with read-only access
(OAuth scope fspt-r) so my AI assistant (Meta Muse) can analyze
my own Yahoo Fantasy Football leagues — 3 NFL leagues under my
own account — and give me recommendations: waiver-wire and
free-agent pickups, trade evaluations, and roster optimization.

## Guardrails
- Read-only. No write access is requested or used.
- The assistant cannot add/drop players, set lineups, or make
  trades. It only makes recommendations; I make every move
  myself in Yahoo.
- Single user only: the account holder. Only my own leagues.
- Non-commercial. Not distributed, sold, or shared.
- No data is published or given to any third party.
